# cuda-string-engine
# CUDA String Engine: Zero-Copy GPU String Processing in Modern C++  A lightweight, modular C++/CUDA engine demonstrating production-grade memory management, Arrow-style string representation (`offsets` + `chars`), and separate compilation pipelines on NVIDIA GPUs.  Verified and benchmarked on **NVIDIA Tesla T4 (Turing, 40 SMs)** using Modal.
